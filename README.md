E-CARPTDSC Benchmark Instances

This repository provides benchmark instances for the Electric Capacitated Arc Routing Problem with Time-Dependent Service Costs (E-CARPTDSC).

Benchmark Test Sets

Two benchmark test sets are provided:

e-tdgdb: 23 small-scale instances containing 11–55 required tasks.

e-tdval: 34 large-scale instances containing 39–97 required tasks.

The benchmark instances incorporate vehicle capacity constraints, battery constraints, intermediate recharging operations, and time-dependent service costs.

Instance Format

Each instance contains information about the road network, required tasks, vehicle capacity, battery capacity, recharging stations, and time-dependent service costs.
